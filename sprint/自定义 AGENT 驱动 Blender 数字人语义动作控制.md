**需求**  
作为使用 VS Code 自定义 AGENT 的用户，我希望通过自然语言指令控制 Blender 中的数字人进入受限的语义动作状态，使我无需直接操作 Blender 或骨骼参数，就能让数字人根据对话意图做出一致、可控、可回退的反馈。

**范围**  
本迭代只支持 4 个语义动作：`thinking`、`confirming`、`neutral_idle`、`restrained_apology`。  
不支持骨骼、shape key、rig、舞蹈、攻击等低层或越界控制。

**验收标准**

1. 用户通过自定义 AGENT 输入中文或英文自然语言请求后，系统能解析为一个受支持的语义动作。
2. 系统调用本地 Blender 控制链路后，能返回结构化反馈，至少包含所选动作、是否 acknowledged、状态和 detail。
3. 当请求超出受支持范围时，系统必须明确拒绝，并给出最接近的受支持动作建议。
4. 当 Blender 不可用时，系统必须返回清晰失败原因，不能静默失败或抛出不可读栈信息。
5. 整个控制链路不允许绕过语义动作边界，不能直接把自然语言转成骨骼级命令。
